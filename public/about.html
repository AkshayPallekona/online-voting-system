About This Project

This is an educational demonstration of an Online Voting System built with Node.js, Express.js, MySQL, and vanilla JavaScript.

It demonstrates user registration, authentication with sessions, election management, candidate management, secure voting with transaction guarantees, and result visualization.

Disclaimer: This is not a certified voting platform. It does not provide cryptographic ballot secrecy, independent verification, or the security guarantees required for real public elections. The database stores the association between voters and their selections for demonstration purposes.

Built for college project and learning purposes.
